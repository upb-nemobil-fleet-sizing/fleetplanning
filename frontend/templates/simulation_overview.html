Stagnationstoleranz

Lässt die Suche einen Schritt akzeptieren, der das Ergebnis nur geringfügig verschlechtert, statt bei jedem nicht verbessernden Schritt sofort abzubrechen. Wirkt auf das Cab-Wachstum in beiden Suchstrategien sowie, in der adaptiven Suche, auf den Pro-Test.

Parameter für Adaptive Suche

Bevor die adaptive Suche einen Pro endgültig entfernt, testet sie zunächst, ob sich der Wegfall durch zusätzliche Cabs ausgleichen lässt. Die folgenden Einstellungen steuern dieses Testverhalten.

Anzahl der Pros, die pro Durchlauf maximal getestet werden, bevor die Suche aufgibt. Bei 0 entfällt dieser Test vollständig: Sobald eine Pro-Entfernung das Ergebnis nicht verbessert, bricht die Suche sofort ab, ohne zu prüfen, ob zusätzliche Cabs das ausgleichen könnten.
Ein Pro, dessen Test bereits gescheitert ist, wird sonst für den Rest der Phase nicht erneut geprüft. Diese Option lässt einen erneuten Test zu, sobald der Test eines anderen Pro erfolgreich war.
Bringt das Hinzufügen von Cabs im Test keine Verbesserung, wird zusätzlich geprüft, ob die Cab-Anzahl sogar unter den Ausgangswert sinken kann.
Wächst die Cab-Anzahl im Test in einem Schritt um mehr als ein Fahrzeug, wird anschließend geprüft, ob der gesamte Zuwachs tatsächlich erforderlich war.
