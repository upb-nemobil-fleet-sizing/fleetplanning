# Optional demo KPI allow-list for the Simulationsergebnisse page.
#
# Format:
# one KPI key per active line
#
# Lines starting with "#" are comments. Inline comments after "#" are ignored.
# If this file is missing, empty, or contains only comments, all currently
# available KPIs remain visible.
#
# To reduce the visible demo KPIs, uncomment only the keys that should remain
# selectable in the Y-axis dropdowns. The X-axis "numCabs" is always kept.
#
# Curation principle (re-done 2026-08-04, see project memory for the "too many
# totals, too few averages" discussion): raw totals (sums of distance/time/
# energy/counts) mostly just track fleet size or fulfilled-request volume, so
# comparing two of them rarely reveals anything a human wouldn't already infer
# from numCabs/rejects - they're kept commented for reference but not
# surfaced. Ratios/averages/outcome metrics that normalize away scale (and
# therefore can show a genuine efficiency difference between iterations) are
# kept active.
#
# Exception (added 2026-08-05): a raw total that's a direct input to an active
# derived KPI stays active too, even though it "just tracks fleet size" on its
# own - hiding it would make the derived number unauditable. cab_total_
# customer_trips is the one case of this today (it's the shared denominator
# of averageCustomerTripCostEur/averageProfitPerTripEur).
